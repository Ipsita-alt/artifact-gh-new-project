# Artifact GH Project

A demo project used to practice GitHub Actions workflows for artifact handling in CI/CD pipelines.

## What it does

- Runs a GitHub Actions workflow (`.github/workflows`) that downloads build artifacts as part of the pipeline
- Includes a small JavaScript/Vite front-end app used as the sample project for the pipeline to build and process

## Tech Stack

- **GitHub Actions** – CI/CD workflow automation
- **Vite** – front-end build tooling
- **JavaScript / HTML**

## Why I built this

To practice artifact management within GitHub Actions pipelines — specifically downloading and handling build artifacts as part of a CI/CD workflow, a common pattern in real-world deployment pipelines.
